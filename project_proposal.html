2. Proposed Problem and Solution – Idea 1

Problem: Students often struggle to simultaneously listen to lectures and take comprehensive notes. Important information is frequently missed, and manually rewriting notes after class wastes valuable study time. There is currently no mobile solution that fully automates this process in a structured and organized way.
Proposed Solution: Develop an AI-Powered Lecture Summarizer mobile application. The app allows students to record live lectures or upload existing audio files. It uses two AI models working in sequence: the first model (Speech-to-Text) converts the audio into a full written transcript, and the second model (Large Language Model) analyzes the transcript to generate a structured summary, key points, key terms, and quiz questions. Lectures are organized into files and subject-based folders, allowing students to manage their entire semester's content in one place.

3. Proposed Problem and Solution – Idea 2

Problem: Poetry enthusiasts and students who memorize poems and verses lack an interactive tool to practice their recitation and receive objective feedback on their mistakes. Practicing alone provides no correction mechanism, making it difficult to identify and fix errors.
Proposed Solution: Develop a Smart Poetry Recitation Trainer mobile application. The user types or pastes any poem of any length into the app, then attempts to recite it from memory using the microphone. The app uses two AI models: the first (Speech-to-Text) converts the spoken recitation into text, and the second (Text Comparison and Error Detection) compares it against the original poem, identifies mistakes such as missing, replaced, or reordered words, and notifies the user with precise, highlighted feedback.

5. Reason for Selecting the Project

We selected the AI-Powered Lecture Summarizer because it addresses a universal and daily problem faced by every university student. The project is technically well-suited for a Mobile Application Development course, as it demonstrates key mobile development concepts including audio recording, API integration, cloud storage, local database management, state management, and dynamic UI rendering. The use of two AI models — a Speech-to-Text model (OpenAI Whisper) and a Large Language Model (Google Gemini) — makes the project technically advanced while remaining achievable within the 10-week timeframe. The organizational feature that groups lectures by subject and semester adds practical value beyond simple summarization, making this a complete and deployable product. The application can also be extended in the future with features such as multilingual support, voice-based quizzing, and cross-device synchronization.
